# Domain Docs

에이전트가 이 저장소를 탐색하기 전에 읽을 도메인 문서와 소비 규칙입니다.

## 탐색 전 읽기

- 루트의 `CONTEXT.md`
- 작업 영역과 관련된 `docs/adr/`의 ADR

파일이나 디렉터리가 없으면 조용히 계속 진행합니다. 처음부터 생성을 제안하지 않습니다. 새로운 용어나 결정이 실제로 합의될 때 `/domain-modeling` 흐름에서 필요에 따라 추가합니다.

## 구조

이 저장소는 단일 컨텍스트를 사용합니다.

```text
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

`CONTEXT-MAP.md`나 하위 컨텍스트별 `CONTEXT.md`는 사용하지 않습니다. 저장소가 실제 다중 패키지 구조로 바뀌기 전에는 다중 컨텍스트로 확장하지 않습니다.

## 용어 사용

이슈 제목, 명세, 리팩터링 제안, 가설, 테스트 이름에서 도메인 개념을 사용할 때는 `CONTEXT.md`에 정의된 용어를 그대로 사용합니다. 명시적으로 피하도록 한 동의어로 바꾸지 않습니다.

필요한 개념이 용어집에 없다면 임의의 새 용어를 만들지 않습니다. 기존 언어로 표현할 수 있는지 먼저 확인하고, 실제 공백이면 `/domain-modeling`에서 합의할 항목으로 기록합니다.

## ADR 충돌

제안이나 구현이 기존 ADR과 충돌하면 조용히 덮어쓰지 않고 충돌하는 ADR과 재검토 이유를 명시합니다.
